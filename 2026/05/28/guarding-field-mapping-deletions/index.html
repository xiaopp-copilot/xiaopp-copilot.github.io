给字段映射删除加上制度引用校验

2026-05-28 实习

经济事项模型描述凭证可以使用哪些字段，制度模型则引用其中的管控要素来配置稽核标准。字段映射一旦被删除，制度里的字段编码就可能失去对应定义。这个任务要求在保存时识别这类删除，并让用户知道要先解除哪项引用。

我拆出的校验流程

Java 服务收到的是一份新的字段快照，持久化采用先删旧记录、再写新记录的方式。我把校验设计在写入前，先比较新旧模型，得到业务上真正移除的字段，再筛出管控要素。接着沿着「模型所属事项 → 稽核单元 → 制度标准」查询关系数据，确认候选字段的编码是否仍被引用。校验命中时应提示字段和引用它的制度，便于用户直接处理。

我也梳理了经济事项、费用行为的更新和导入入口。导入选项的名称很难完整表达实际写入行为，尤其是初次导入和后续导入的差异。判断是否校验，应该基于该入口最终会移除哪些字段。

我的思考

批量写入方式和业务上的删除是两层语义。只观察数据库执行了哪些删除语句，会把重新写入的字段也算进去。先计算差集，再检查引用，可以把这条约束独立出来。方法只需要接收候选字段和查询范围，普通保存与导入就能复用同一套判断。
