为表单设计器设计经济事项模型查询接口

2026-06-16 实习

表单设计器需要根据报销单编码确定可以配置哪些经济事项和扩展字段。我设计了一个 Java SDK 查询接口，经 Feign 调用后一次返回表单所需的信息，调用方可以直接拿到事项、费用行为和扩展字段树。

接口产出

查询先根据报销单编码找到可用的经济事项，再通过关系数据取得费用行为。响应保留事项和费用行为的业务编码、唯一码、名称，并将模型树里的叶子标记转换为调用方关心的「是否分组」。扩展字段只聚合基础信息、报销单信息两棵子树。改造后用原有响应样例核对了输出形状。

我的思考

我把 AI 用在补齐实现和初步审查上。给出明确的入口参数、字段来源、分组语义与预期结果，生成的代码才有具体的核对标准。审查时也要计算查询代价。经济事项、费用行为和建模字段如果都在循环里逐项查询，很容易叠加成 N+1。把这三类数据分别批量取出，再按事项归组，是值得优先检查的优化方向。

另一个需要约定的是失败语义。空结果可以表示该报销单没有可用配置。依赖查询失败时，调用方应能区分这两种情况，避免把暂时查不到当成真的没有可配置项。
