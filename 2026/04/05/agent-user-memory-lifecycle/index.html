让 Agent 的用户记忆可以纠正、隔离和删除

2026-04-05 Agent

用户说「这次用英文写」，与「以后我的周报都用英文」表达了不同的范围。我会把会话要求留在当前任务，把明确的长期偏好写成一条可更新的记录，并保存用户、适用范围、证据和更新时间。这样未来遇到新要求，可以定位到该修改哪一条。

写入和读取分别做判断

写入时先把候选条目分类成事实、长期偏好或当前要求。只存对后续任务有价值、来源明确的条目，避免把模型推断和文档里的文字当成用户确认。读取时先按账号和工作空间筛选，再根据任务挑选少量相关记忆。保留结构化值和来源，用户才能追问系统为什么用了某条偏好。

测一下改口和删除

我会构造四轮对话。用户先设定周报语言，随后只对一次周报临时换语言，再修改长期偏好，最后要求删除。分别验证临时要求结束后长期偏好能恢复、明确纠正能覆盖旧值、删除后索引与缓存也不会继续命中。用另一账号跑相同问题，可以顺手验证隔离边界。

我的取舍是先做少量、可解释的记忆。等验证了纠正与删除，再扩大可保存的类型。

参考李博杰《深入理解 AI Agent：设计原理与工程实践》§3.1。
