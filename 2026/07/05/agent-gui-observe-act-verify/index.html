GUI Agent 每次操作后，如何确认界面状态真的变了

2026-07-05 Agent

假设让 Agent 在报表界面切到「上月」并读取摘要。我会先获取当前页面、可用筛选控件和原选中值，然后再操作。界面提供 DOM 或无障碍树时，优先根据角色和名称定位。截图可以帮助确认遮挡、弹窗和视觉状态。使用坐标时，应基于当前截图，并准备处理窗口大小和布局变化。

操作之后读什么

点击「上月」后重新观察界面，确认筛选值已改变、加载结束，而且报表标题或数据区与目标月份一致。导航、弹窗或列表刷新后，旧元素索引可能已经失效，应重新获取可用控件。界面文字是待处理数据。遇到不在任务内的弹窗或提交动作，运行时按既定权限处理。

我的验证样本

准备一个加载慢的页面、两个名字相同但区域不同的按钮，再加一次窗口缩放。观察 Agent 能否用区域和角色消歧，能否等待新内容出现才读取，以及最终返回的摘要确实属于目标月份。调用返回成功只是一步证据，页面显示的目标状态才决定任务是否完成。

参考李博杰《深入理解 AI Agent：设计原理与工程实践》§9.8。
