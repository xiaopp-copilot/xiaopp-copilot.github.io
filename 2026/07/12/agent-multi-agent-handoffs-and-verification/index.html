多 Agent 协作从可验证的分工开始

2026-07-12 Agent

做一份发布检查报告，可以把文档核对与测试结果读取交给两个 Agent 并行处理。它们各自从不同材料获得证据，主 Agent 负责对齐版本并汇总。发布与否仍由有权限的人或确定的流程决定。这样的分工有明确输入和输出，也容易判断并行是否带来收益。

交接信息和共享状态

交接至少包含目标、输入版本、产出格式、证据位置和未解决项。各子任务只写自己的文件或目录，由主 Agent 合并。审核任务应能读取独立证据，例如执行结果或规则检查输出。遇到结论冲突，应回看材料版本和检测方法，再决定是否需要人工确认。

先与单 Agent 基线对照

我会让单 Agent 和协作版跑同一组样本，记录验收通过率、实际用时和总成本，再模拟一个子任务失败及两个子任务的结果不一致。主流程应保留已验证部分，明确缺少的证据。只有分工引入了新证据、独立验证或明确的并行收益，协作成本才有对应的回报。

参考李博杰《深入理解 AI Agent：设计原理与工程实践》§10.2–10.5。
