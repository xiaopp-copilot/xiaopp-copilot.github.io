Linux、Docker 与 Maven：部署、打包和线上排障

进程、线程和进程间通信

进程通常拥有独立地址空间和资源，操作系统以线程为执行调度单位。线程共享进程的堆和文件描述符等资源，各有调用栈、程序计数器和寄存器状态。进程隔离可以缩小普通故障的范围，线程出现未捕获异常时，具体影响由语言运行时和应用处理方式决定。

IPC 常见方式有管道、消息队列、共享内存、信号、信号量和 Socket。共享内存可减少复制，但共享状态需要另做同步。信号常用于通知，信号量用于协调并发访问，Socket 也可以跨机器。

Linux 常用命令

场景 命令
文件和目录 ls -l 看详情，ls -a 看隐藏项，cd 切目录，pwd 查路径，mkdir -p 建多层目录，touch 创建文件或更新其时间，cp -r 复制目录，mv 移动或重命名，find . -name '*.log' 按名称找文件，rm -rf 强制递归删除
查看或编辑文本 cat 查看，more、less 分屏，head -n 10 读开头，tail -n 10 读末尾，tail -f 跟踪追加，grep 按内容过滤，vi、vim 编辑
权限与用户 chmod 755 FILE 设置权限，chown USER:GROUP FILE 设置属主和组，sudo 按授权切换身份执行，whoami 查当前身份，passwd 改密码
系统和进程 ps -ef 查进程，top 看资源，kill PID 请求退出，kill -9 PID 强制结束，free -h 查看内存，df -h 查文件系统容量，du -sh DIR 查目录大小，uptime 看运行时长和负载

压缩归档 tar -zcvf archive.tar.gz DIR 打包，tar -zxvf archive.tar.gz 解包，zip -r archive.zip DIR 和 unzip archive.zip 处理 ZIP
辅助 man 查手册，history 查历史，clear 清屏，echo "$PATH" 查命令搜索路径，ln -s SRC LINK 建符号链接

cp 能远程复制吗？ 深势科技一面问过。cp 操作当前系统可访问的文件路径，所以可复制已经挂载的远程文件系统。要经 SSH 直接传到远端，可用 scp local.txt user@host:/path/。目录重复同步或大文件传输还可以用 rsync -av --partial local/ user@host:/path/，借助增量复制和保留部分传输进度来降低重传成本。

Docker 怎么访问宿主机上的文件和服务

锐捷一面原题。 镜像打包应用和依赖，容器提供隔离的运行环境。Linux 容器用 namespaces 管理可见范围，用 cgroups 约束资源，通常共享宿主内核。

可以用 Bind Mount 将特定宿主机路径挂载到容器中，例如 --mount type=bind,src=/srv/app/config,dst=/app/config,readonly，也可以使用 -v。用 docker inspect 查挂载来源与目标，用 docker exec 在容器里确认路径、文件和权限。Docker 管理的 named volume 适合容器数据持久化或多个容器共享文件。

若要访问宿主机的 MySQL、Redis 等网络服务，Docker Desktop 常提供 host.docker.internal，原生 Linux 可按环境配置 --add-host=host.docker.internal:host-gateway，也可评估 Host 网络。还要确认服务监听地址、访问权限、防火墙和容器网络。

Maven 的打包命令

mvn package 运行到打包阶段，mvn clean package 先清理旧构建输出。-DskipTests 跳过常见的测试执行阶段，通常仍会编译测试。-Dmaven.test.skip=true 可让支持该属性的编译和测试插件跳过测试编译与执行。要把产物安装到本机 Maven 仓库供其他项目引用，用 mvn clean install。Maven Surefire 跳过测试说明

Java 服务 CPU 飙升怎么定位

面试原题。 先确认影响节点和时间范围，再判断是哪个进程、哪个线程和哪段代码。

把 top 找到的十进制线程 ID 转成十六进制，对照线程转储里的 nid=0x…。可间隔采样多份转储，区别短暂热点、持续忙循环、锁竞争和 GC 活跃。观察 JVM 内存与 GC 参数见 JVM 与 GC。

多节点日志怎么找？ 我用 Loki 汇集日志、Grafana 查询与查看。在明确异常窗口后，按 TraceID、节点、时间和错误码关联同一次调用，沿网关、服务和下游定位首个异常点。定位哪个节点开始异常后，再回看当时版本、请求量、GC 和线程状态。
